# TradPlus HyBid Adapter Swift Package

Swift Package Manager support for the TradPlus HyBid adapter (15.15.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-HyBid.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-HyBid.git", exact: "15.15.0")
```

Third-party dependency: HyBid SDK `3.9.1` via vervegroup/hybid-ios-spm-sdk. Verve and HyBid are the same platform.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.15.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
